rclone-starnet

rclone-starnet is a private, personal tool. It is not offered to the public.

Privacy policy

The tool copies its owner's own report files from their own computer to their own Google Drive, using the open-source program rclone.

  • It can only see files it created itself (Google Drive scope drive.file).
  • It collects, stores and shares no data about anyone else.
  • Nothing is sold, shared with third parties or used for advertising.
  • Access can be removed at any time at myaccount.google.com/permissions.
